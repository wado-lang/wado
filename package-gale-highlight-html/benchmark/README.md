# gale-highlight-html Benchmark

Highlights one HTML page and reports throughput. Each highlighter here picks
the language of each embedded region from its context, as
`gale-highlight-html` does.

```sh
mise run benchmark-gale-highlight-html
```

## Input

`input.html` (39705 bytes) is a documentation page that carries every region
the highlighter switches language for:

- a `<style>` holding `package-gale/benchmark/css/input.css`
- a `<script>` holding `benchmark/microgpt/microgpt.js`
- a JSON-LD `<script type="application/ld+json">`
- markup with `style="..."` and `on*="..."` attributes, void elements and
  entities

Each arm checks once, before timing, that its output colours a JavaScript
keyword and a CSS property. An arm that left the regions as plain text would
fail that check rather than look fast.

## Highlighters

| Highlighter               | How it reads the page                                                 | Regions it leaves out                                     |
| ------------------------- | --------------------------------------------------------------------- | --------------------------------------------------------- |
| **Gale** (Wado)           | ANTLR4 grammars from grammars-v4, parsers generated by Gale           | none                                                      |
| tree-sitter (Rust native) | `tree-sitter-html` with JavaScript, CSS and JSON injected             | `style="..."`: `tree-sitter-css` parses only a stylesheet |
| Prism.js                  | regular expressions; `markup` inlines the CSS and JavaScript grammars | none, but it reads JSON-LD as JavaScript                  |

The stock `tree-sitter-html` injections cover only `<script>` and `<style>`
bodies. `tree_sitter.rs` adds JSON for a JSON `type` and JavaScript for an
`on*` attribute.

## Results

Environment: Wado 2026-10-03 (`-O2`), wasmtime 49.0.0, rustc 1.98.1,
Node.js v26.7.0, Linux x86_64. Best of three runs.

| Implementation            | Throughput |   ms/iter | vs best |
| ------------------------- | ---------: | --------: | ------- |
| Prism.js                  |  4.17 MB/s |  9.518 ms | 1.00x   |
| tree-sitter (Rust native) |  3.51 MB/s | 11.300 ms | 1.19x   |
| **Gale** (Wado)           |  2.45 MB/s | 16.178 ms | 1.70x   |

## Files
