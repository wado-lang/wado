httpbin

HTTP request & response inspection service, built with Wado.

Endpoints

GET /get
Returns request info (headers, query params, url).
POST /post
Returns request info including body.
PUT /put
Returns request info including body.
PATCH /patch
Returns request info including body.
DELETE /delete
Returns request info.
GET /headers
Returns request headers as JSON.
GET /ip
Returns origin IP.
GET /user-agent
Returns User-Agent string.
GET /status/:code
Returns the given HTTP status code.
GET /base64/:value
Decodes base64-encoded string.
* /anything
Returns request info for any HTTP method.
